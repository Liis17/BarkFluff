Политика удаления аккаунта

📅 Дата вступления в силу: 24 января 2026 г. 🔄 Последнее обновление: 24 января 2026 г.

1. Введение

В BarkFluff мы уважаем ваше право на контроль над вашими персональными данными. В соответствии с требованиями GDPR (General Data Protection Regulation) и другими законами о защите данных, вы имеете право в любое время удалить свой аккаунт и связанные с ним данные.

Настоящий документ подробно описывает:

  • ✅ Как удалить свой аккаунт
  • ✅ Какие данные удаляются
  • ✅ Какие данные сохраняются (и почему)
  • ✅ Возможность восстановления аккаунта
  • ✅ Опции полного удаления всех данных

2. Как удалить аккаунт

2.1 Через клиентское приложение

Desktop-клиент (WPF):

  1. Откройте Настройки (Settings)
  2. Перейдите в раздел Аккаунт (Account)
  3. Прокрутите вниз до секции Удаление аккаунта (Delete Account)
  4. Нажмите кнопку "Удалить мой аккаунт" (Delete My Account)
  5. Подтвердите действие, введя свой пароль
  6. Прочитайте предупреждение о последствиях удаления
  7. Нажмите "Да, удалить навсегда" (Yes, Delete Forever)

2.2 Через API (для разработчиков)

gRPC метод:

service UsersApi {
  rpc DeleteAccount(DeleteAccountRequest) returns (DeleteAccountResponse);
}

message DeleteAccountRequest {
  string password = 1; // Подтверждение пароля
  string reason = 2;   // Опциональная причина удаления
}

2.3 Через службу поддержки

Если у вас нет доступа к аккаунту (забыт пароль, утерян доступ к email):

  1. Отправьте запрос на privacy@barkfluff.com
  2. Укажите:
    • Имя пользователя (Username)
    • Email, использованный при регистрации
    • Причину, по которой вы не можете войти
    • Доказательства владения аккаунтом (опционально: скриншоты, информация о последних сообщениях)
  3. Мы проверим запрос и удалим аккаунт в течение 7 рабочих дней

3. Двухэтапный процесс удаления

BarkFluff использует двухэтапную систему удаления для защиты от случайного удаления и обеспечения возможности восстановления.

Этап 1: Мягкое удаление (Soft Delete) — 30 дней

Что происходит:

  • ✅ Аккаунт помечается флагом IsDeleted = true в базе данных
  • ✅ Вход в систему заблокирован (вы не можете войти в приложение)
  • ✅ Ваш профиль скрыт от других пользователей
  • ✅ Вы не отображаетесь в поиске пользователей
  • ✅ Онлайн-статус не обновляется
  • ✅ Уведомления о новых сообщениях не отправляются

Что НЕ происходит:

  • ❌ Данные НЕ удаляются физически (остаются в базе данных)
  • ❌ Сообщения НЕ удаляются (другие участники чатов все еще видят их)
  • ❌ Файлы НЕ удаляются из хранилища

Период восстановления: 30 дней с момента удаления.

Как восстановить аккаунт:

  1. Отправьте запрос на support@barkfluff.com
  2. Укажите: Username, Email, Причину восстановления (опционально)
  3. Мы проверим запрос и восстановим аккаунт в течение 48 часов

Этап 2: Жесткое удаление (Hard Delete) — после 30 дней

По истечении 30-дневного периода начинается автоматическое необратимое удаление данных.

Что удаляется полностью:

Данные Статус
Запись в таблице Identity.Users ✅ Удалена (Email, Username, Password Hash)
Профиль пользователя (Users.UserProfiles) ✅ Удален (FirstName, LastName, Bio)
Аватар ✅ Удален из S3 и метаданные из PostgreSQL
Все активные сессии (Identity.Sessions) ✅ Удалены (Refresh Tokens, Device IDs)
Личные файлы ✅ Удалены (файлы, загруженные только вами и не прикрепленные к сообщениям)
Настройки конфиденциальности ✅ Удалены
История входов (старше 90 дней) ✅ Удалена

Что сохраняется:

Данные Причина сохранения Что изменяется
Сообщения в групповых чатах Сохранение целостности истории чатов для других участников SenderId заменяется на NULL или отображается как [Удаленный пользователь]
Сообщения в приватных чатах Обеспечение доступа к истории для второго участника SenderId заменяется на NULL, отображается как [Удаленный пользователь]
Вложения в сообщениях Сохранение целостности сообщений Остаются доступными для других участников чатов
Журналы безопасности (последние 180 дней) Требования законодательства, расследование инцидентов безопасности Ничего не требуется

Почему сообщения сохраняются?

  • Технические причины: Удаление всех ваших сообщений нарушит целостность истории чатов для других участников
  • Юридические причины: Некоторые юрисдикции требуют хранения коммуникаций в течение определенного периода

4. Экспорт данных перед удалением

Перед удалением аккаунта мы настоятельно рекомендуем экспортировать свои данные.

4.1 Как экспортировать данные

Через клиентское приложение:

  1. Откройте Настройки → Аккаунт → Конфиденциальность
  2. Нажмите "Экспортировать мои данные" (Export My Data)
  3. Дождитесь подготовки архива (может занять несколько минут)
  4. Скачайте ZIP-файл

4.2 Что входит в экспорт

Формат: JSON + вложенные файлы (ZIP-архив)

Содержимое:

  • Данные профиля (userId, username, email, firstName, lastName, bio)
  • Все ваши сообщения с текстом и вложениями
  • Список чатов с участниками
  • Загруженные файлы с ссылками для скачивания
  • История сессий (устройства, IP-адреса)

5. Последствия удаления аккаунта

5.1 Что происходит с вашими данными

Элемент Последствие
Вход в систему Невозможен (username и email освобождаются и могут быть зарегистрированы снова)
Профиль Удален, недоступен для поиска
Аватар Удален
Приватные сообщения Отображаются у других пользователей как [Удаленный пользователь]
Групповые сообщения Отображаются как [Удаленный пользователь]
Файлы в чатах Остаются доступными (опция полного удаления — по запросу)
Активные сессии Все устройства разлогинены

5.2 Что происходит с чатами

  • Приватные чаты: Остаются в списке чатов у второго участника, но ваш профиль отображается как [Удаленный пользователь]
  • Групповые чаты: Вы автоматически покидаете все групповые чаты, но сообщения остаются

5.3 Повторная регистрация

После удаления аккаунта:

  • ✅ Вы можете зарегистрироваться снова с тем же email или username (после завершения жесткого удаления)
  • ❌ Вы НЕ восстановите старые данные (сообщения, чаты, файлы)
  • ❌ Вы НЕ сможете связать новый аккаунт со старым

Это будет полностью новый аккаунт без связи с предыдущим.

6. Частичное удаление данных

Если вы не хотите удалять аккаунт полностью, но хотите удалить определенные данные:

6.1 Удаление отдельных сообщений

Как удалить:

  1. Откройте чат
  2. Нажмите и удерживайте сообщение
  3. Выберите "Удалить" (Delete)
  4. Выберите опцию:
    • "Удалить для себя" — сообщение удаляется только у вас
    • "Удалить для всех" — сообщение удаляется у всех участников (доступно в течение 48 часов после отправки)

6.2 Удаление файлов

Личные файлы:

  1. Откройте Настройки → Файлы и медиа
  2. Выберите файлы для удаления
  3. Нажмите "Удалить"

7. Ответы на частые вопросы (FAQ)

Q1: Могу ли я восстановить аккаунт после жесткого удаления?
A: Нет, после жесткого удаления (через 30 дней) восстановление невозможно.

Q2: Смогут ли другие пользователи видеть мои сообщения после удаления аккаунта?
A: Да, но ваше имя будет отображаться как [Удаленный пользователь].

Q3: Что происходит с групповыми чатами, которые я создал?
A: Администраторские права автоматически передаются следующему участнику.

Q4: Удаляются ли мои данные из резервных копий?
A: Резервные копии удаляются в соответствии с нашей политикой хранения (обычно в течение 90 дней).

Q5: Могу ли я удалить аккаунт, если забыл пароль?
A: Да, обратитесь в службу поддержки: privacy@barkfluff.com

Q6: Сколько времени занимает полное удаление?
A: Мягкое удаление — мгновенно. Жесткое удаление — автоматически через 30 дней.
