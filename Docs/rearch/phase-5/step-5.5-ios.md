# Этап 5.5 — iOS: федерация в экранах поверх общих пакетов

## Цель

iOS-приложение получает тот же федеративный функционал, что и macOS. Транспорт и домен уже сделаны в 5.4 (общие пакеты `BFProto`/`BFNetworking`/`BFCore` подключены в iOS-проект по относительному пути) — здесь только iOS-экраны и их ViewModel'ы.

Критерий роадмапа: E2E «нашёл → написал → получил ответ» на iOS.

## Контекст

- Контракт — `Obsidian/ClaudeVault/Клиенты/Federation-ClientGuide.md` (5.1). **Референс реализации — macOS (5.4)**: смотри, как ровно те же сценарии сделаны в `Mac/Barkfluff/Barkfluff/Features/**`, и повторяй логику, адаптируя вёрстку под iOS. Это действующее правило проекта для iOS (`Obsidian/ClaudeVault/Клиенты/iOS.md`).
- Карты — `Клиенты/iOS.md`, `iOS-ProjectMap.md`; дизайн — `Клиенты/DesignDocument.md`.

## Предпосылка

Этап 5.4 завершён и закоммичен: в `BFCore`/`BFNetworking` уже есть резолв FID, отправка по uuid, uuid-ветка статусов/typing, типизированные ошибки федерации и `federationAvailable` из `ConnectionManager`. **Если чего-то из этого нет — не дописывать в пакетах здесь**, а остановиться: правки общих пакетов принадлежат 5.4, иначе macOS и iOS разъедутся.

## Изменение 1 — поиск и карточка remote-пользователя

`UserSearchViewModel`/`UserSearchView`: ввод похож на FID (парсер из `BFCore`, 5.4) и `federationAvailable` → `resolveFederatedUser` вместо `searchUsers`; результат — одна карточка с FID; `found = false`/ошибка — текст из гайда. Существующие дебаунс и минимальная длина сохраняются.

## Изменение 2 — переписка и отображение

1. Открытие чата с remote-пользователем и первое сообщение — через uuid-путь `ChatService`/`MessagesRepository` (5.4).
2. Шапка чата и строки списка чатов: бейдж/подпись ноды у remote-собеседника, полный FID в шапке; servername — как пришёл (punycode), без декодирования.
3. `federated_read_by` объединять с `read_by` при отрисовке «прочитано».
4. Typing от remote (по uuid) — «@bob:node печатает…»; статус `UNKNOWN` для remote — «нет данных», не «был(а) давно».
5. Подписка на статусы включает `user_uuids` (метод пакета уже это умеет — убедиться, что iOS-экран его использует).

## Изменение 3 — вложения недоступного origin

Карточка/плитка рисуется по метаданным сообщения сразу; `503` → placeholder «Сервер собеседника недоступен» + повтор по тапу; `404` → «Файл недоступен» без повтора. Проверить, что путь загрузки картинок (Nuke) не ретраит бесконечно на 503 и не кеширует ошибочный ответ как изображение. `file_name` экранировать при показе и санитизировать при «Сохранить в Файлы».

## Изменение 4 — настройка приватности

`PrivacySettingsView`: переключатель «Разрешить сообщения с других серверов» = `!deny_federated_dm`, подпись «действует только на новые переписки», виден только при `federationAvailable`.

## Изменение 5 — локализация и документация

- Новые строки — в `iOS/.../Localizable.xcstrings`, все пять языков (строки, живущие в `BFCore`, уже переведены в 5.4 — не дублировать).
- `Obsidian/ClaudeVault/Клиенты/iOS.md` — раздел «Федерация» + ссылка на `[[Клиенты/Federation-ClientGuide]]`; `iOS-ProjectMap.md` — новые файлы, если появились.

## Чего НЕ делать

- Не менять общие пакеты (`Mac/Barkfluff/Packages/**`) — это 5.4. Обнаружил пробел → останови этап и сообщи.
- Не трогать macOS-таргет и остальные клиенты.
- Не вводить iOS-специфичные визуальные решения там, где macOS уже определил паттерн (бейдж ноды, тексты ошибок) — консистентность важнее локальной эстетики.

## Критерии готовности

1. Сборка: `xcodebuild -project iOS/Barkfluff/Barkfluff.xcodeproj -scheme Barkfluff -configuration Debug build` (или актуальная схема) — успех; при недоступности toolchain в окружении — явно зафиксировать в отчёте.
2. Диф этапа не содержит изменений в `Mac/**` (кроме, возможно, `.xcstrings` при явной необходимости — если пришлось, объяснить в коммите).
3. При `federation_enabled = false` поведение приложения не отличается от текущего.
4. Новые строки — во всех пяти языках.
5. Паритет с macOS: пройтись по чек-листу 5.4 (Изменение 4, пункты 1–6) и убедиться, что каждый сценарий имеет iOS-аналог.

7. Obsidian обновлён (Изменение 5).
