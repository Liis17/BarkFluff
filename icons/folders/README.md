# Иконки папок чатов

Набор из 49 системных SVG-иконок, которые пользователь может выбрать для папки чатов. Полный каталог ключей и назначений находится в [`../README.md`](../README.md).

## Контракт

- Имя файла без `.svg` — значение `folder_icon`: `work`, `travel`, `unread` и т.д.
- SVG рассчитаны на `24×24dp` и безопасную область с отступом около `2dp`.
- Все иконки монохромные: цвет приходит через `currentColor`.
- Фон, контейнер и состояние выбора добавляются компонентом из Material 3-токенов, а не запекаются в SVG.
- Основной вариант — rounded outline: `stroke-width="2"`, круглые caps и joins. Небольшие залитые детали используются только там, где они улучшают распознавание.

## Рекомендованное отображение

Для списка или чипа используйте `on-surface-variant` в обычном состоянии и `on-primary-container`/`primary` для выбранного состояния. Минимальная интерактивная область — `48×48dp`; сама иконка остаётся `24dp`.
