# Иконки настроек

Набор из 14 семантических SVG-иконок для категорий настроек. Имена файлов — kebab-case формы ключей категорий — рассчитаны на использование в iOS, macOS, Android, Windows и Linux-клиентах.

## Контракт

- SVG: `24×24`, `viewBox="0 0 24 24"`.
- Монохром: только `currentColor`, без встроенных цветов и контейнеров.
- Rounded outline: `stroke-width="2"`, круглые caps и joins.
- Фон категории, цветной контейнер и состояние выбора добавляются компонентом интерфейса.
