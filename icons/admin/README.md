# Admin UI icons

Иконки для навигации и управляющих действий админ-панели. Файлы следуют
общему контракту каталога `icons/`: `24×24`, outline, `stroke: currentColor`
и без встроенного контейнера.

В веб-интерфейсе иконка подключается через `assets/icons.js`:

```js
bfIcon('admin/restart', 'size-20')
```

Каталог доступен для других страниц через `/assets/icons/admin/*.svg`.

Общие действия `edit`, `delete` и `download` не дублируются здесь и
переиспользуют соответствующие файлы из `message-actions/`.
