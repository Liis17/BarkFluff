# Боты и Mini-Apps

Parent: [[Ideas/Index]]

Приоритет/область: Средний; платформа.

Bot API уже существует: [[Backend/Bots]] описывает gRPC, HTTP REST, токены, BotFather, встроенные боты и доставку событий. Здесь остаётся предложение расширения платформы.

- Mini-App WebView с ограниченным JavaScript bridge для профиля, отправки сообщения и закрытия окна.
- Нативные кнопки/inline-клавиатуры и команды; единая поддержка вложений.
- Портал управления, SDK C#/Python, sandbox и публичная документация.

Изоляцию WebView, разрешения и проверку identity нужно спроектировать отдельно. Не считать предложенные bridge-методы действующим API. Контракты Bots, права Users и события Messages описываются в соответствующих сервисах; [[Clients/DesignDocument]] — продуктовый ориентир для UI.
