# PIN и биометрия

Parent: [[Ideas/Index]]

Приоритет/область: Безопасность; клиентские платформы.

В Android локальный PIN/app lock/BiometricPrompt не реализован; `SecuritySettingsActivity.kt` управляет серверными OTP-факторами, а не локальной блокировкой.

В текущих Apple UI/BFCore также нет PIN/биометрического app-lock; Keychain для токенов не означает такую блокировку приложения. Linux уже имеет PIN storage/unlock.

Блокировку проверять по реальной платформе: [[Clients/Android]], [[Clients/iOS]], [[Clients/macOS]], [[Clients/Windows-WPF]], [[Clients/Windows-WinUI]], [[Clients/Linux-Qt]]. Цель предложения — унифицировать опыт блокировки на платформах.

- Блокировка на холодном старте и после заданного времени в фоне; PIN/биометрия как альтернативы.
- Настройки задержки, биометрии и скрытия содержимого в переключателе приложений.
- Ограничение попыток и опциональный выход требуют решения о сохранности локальных данных.

Использовать платформенное secure storage и lifecycle; конкретную криптографию и API брать из текущего клиента. Старые примеры `LockManager`/`LockActivity`/bcrypt не описывают Android-реализацию. Скриншоты и app-switcher защита имеют разные платформенные механизмы; не обещать их автоматически через `.privacySensitive()`.
