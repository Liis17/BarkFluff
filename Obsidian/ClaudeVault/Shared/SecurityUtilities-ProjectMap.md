### Методы

#### `EvaluatePasswordStrength(string password) → int`
Оценивает силу пароля и возвращает числовой score от **0 до 100**.

Алгоритм начисления очков:

| Критерий | Баллы |
|----------|-------|
| Длина ≥ 16 символов | +30 |
| Длина ≥ 12 символов | +20 |
| Длина ≥ 8 символов | +10 |
| Есть оба регистра (upper + lower) | +20 |
| Есть только один регистр | +10 |
| ≥ 3 цифры | +20 |
| ≥ 1 цифра | +10 |
| ≥ 2 спецсимвола (`!@#` и т.д.) | +20 |
| 1 спецсимвол | +10 |
| Уникальность символов > 70% | +10 |
| Уникальность символов > 40% | +5 |

Итог ограничен сверху: `Math.Min(score, 100)`.  
Пустая строка или `null` → возвращает `0`.

---

#### `GetPasswordStrengthMessage(int score) → (string message, string colorHex)`
Переводит числовой score в локализованное (🇷🇺 русский) сообщение и hex-цвет для отображения в UI.

| Score | Сообщение | Цвет |
|-------|-----------|------|
| < 20 | «Пароль слишком простой» | `#FF4C4C` (красный) |
| 20–39 | «Пароль всё ещё слишком лёгкий» | `#FF8000` (оранжевый) |
| 40–59 | «Пароль средней сложности» | `#FFD700` (жёлтый) |
| 60–79 | «Пароль достаточно надёжный» | `#7FFF00` (жёлто-зелёный) |
| ≥ 80 | «Надёжный пароль» | `#00CC66` (зелёный) |
