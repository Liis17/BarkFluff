# BarkFluff.Shared.SecurityUtilities

Небольшая `.net10.0` библиотека без внешних зависимостей: `Shared/BarkFluff.Shared.SecurityUtilities/`.

`SecurityUtilities.EvaluatePasswordStrength` возвращает оценку 0–100. Баллы за длину взаимоисключающие: ≥16 — 30, ≥12 — 20, ≥8 — 10. Оба регистра дают 20, один — 10; ≥3 цифр — 20, одна-две — 10; ≥2 не буквенно-цифровых символа — 20, один — 10. Уникальность `Distinct().Count() / Length` выше 70% даёт 10, выше 40% — 5. Пороговые проверки строгие, пустой пароль даёт 0, итог ограничен 100. Символы пробела также считаются не буквенно-цифровыми.

`GetPasswordStrengthMessage` сначала ограничивает вход диапазоном 0–100, затем возвращает пару «сообщение / цвет»: <20 — «Пароль слишком простой» `#FF4C4C`; 20–39 — «Пароль всё ещё слишком лёгкий» `#FF8000`; 40–59 — «Пароль средней сложности» `#FFD700`; 60–79 — «Пароль достаточно надёжный» `#7FFF00`; ≥80 — «Надёжный пароль» `#00CC66`. Это UI-индикатор по эвристике, а не серверная проверка надёжности.

Прямые вызовы находятся в WPF-валидаторе и формах регистрации/сброса пароля. Точки входа: [[Shared/SecurityUtilities-ProjectMap]].
