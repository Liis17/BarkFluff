# 📢 Публичные каналы и подписки

> Категория: Контент
> Приоритет: 🟡 Средний
> Сложность: ⭐⭐⭐⭐

---

## Описание

Возможность создавать **публичные каналы** с односторонней коммуникацией: один или несколько администраторов публикуют контент, подписчики читают. Каналы можно находить через поиск или по @username.

---

## Ключевые возможности

- Публичный / приватный канал
- @username для публичного канала
- Счётчик подписчиков
- Комментарии к постам (через связанную группу)
- Посты с богатым форматированием (Markdown/HTML)
- Автоматические посты через Bots API ([[03-Bots]])
- Верифицированные каналы (синяя галочка)
- Уведомления о новых постах (с настройкой частоты: немедленно / раз в час / беззвучно)
- Пересылка постов в личные чаты

---

## Архитектура

Каналы — расширение существующей концепции чатов в [[../Backend/Messages]]:

```
ChatType enum:
  DIRECT    = 0   (существующий)
  GROUP     = 1   (существующий)
  CHANNEL   = 2   (новый)
```

- Канал хранится как специальный тип чата с флагами `is_channel`, `is_public`, `username`
- Новая таблица `channel_subscriptions(channel_id, user_id, subscribed_at, notify_mode)`
- Новый gRPC метод `SearchChannels(query)` → возвращает публичные каналы
- Индекс username-ов в Redis для быстрого поиска `@handle`

### Права в канале

| Роль | Может писать | Может управлять |
|------|:---:|:---:|
| Owner | ✅ | ✅ |
| Admin | ✅ | ✅ |
| Subscriber | ❌ | ❌ |
