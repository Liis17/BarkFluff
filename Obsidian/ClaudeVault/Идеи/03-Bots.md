## Описание

Открытая платформа для создания **ботов** (автоматических собеседников) и **Mini-Apps** (встроенных веб-приложений внутри мессенджера). По аналогии с Telegram Bot API, но с собственными возможностями — нативные кнопки, inline-клавиатуры, WebView приложения.

---

## Ключевые возможности

### Боты
- HTTP Webhook API для разработчиков (REST)
- Long-polling альтернатива для webhook
- Команды (`/start`, `/help`, кастомные)
- Inline-клавиатуры (кнопки в пузыре сообщения)
- Ответы на сообщения, пересылка
- Боты могут отправлять все типы вложений ([[../Клиенты/DesignDocument]])

### Mini-Apps
- Встроенный WebView внутри клиента
- JavaScript Bridge: `BarkFluff.sendMessage()`, `BarkFluff.getUser()`, `BarkFluff.close()`
- Открываются по кнопке в боте или напрямую из профиля
- Примеры: игры, опросы, платёжные формы, мини-CRM

## Архитектура

```
Разработчик ──► Developers Portal (7020) ──► регистрация бота
                                              получение API токена

Внешний сервер бота ◄──► BarkFluff.Bots (новый сервис, порт 7030)
                             │
                    Webhook / Long-poll
                             │
                    Messages сервис (отправка от имени бота)
```

- Новый микросервис `BarkFluff.Bots` — управление ботами, маршрутизация webhook
- Токен бота авторизует запросы (отдельная схема от XAuth)
- Bot-пользователь — особый тип аккаунта в [[../Backend/Users]] (флаг `is_bot`)
- Разработчик регистрирует бота через [[../Backend/Developers]] портал

## Developer Experience

- Публичный REST API: `POST /bots/{token}/sendMessage`
- Swagger/OpenAPI документация на [[../Backend/Developers]] портале
- SDK библиотека на C# (NuGet) и Python как первые клиенты
- Sandbox среда для тестирования
