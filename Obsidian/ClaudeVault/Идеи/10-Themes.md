> Категория: Персонализация
> Приоритет: 🟢 Низкий

---

## Описание

Полная система **персонализации внешнего вида** мессенджера: темы оформления, кастомные цвета пузырей, фоны чатов, шрифты, иконки пакета — и **виджеты** на домашний экран (Android / iOS / Windows).

---

## Ключевые возможности

### Темы

- Системные темы: светлая / тёмная (уже есть) / AMOLED-чёрная
- Пользовательские темы: акцентный цвет, цвет пузырей входящих/исходящих
- Импорт/экспорт темы (JSON файл)
- Магазин тем (создатели могут публиковать)
- Превью темы до применения
- Разные темы для разных чатов

### Фоны чатов

- Выбор обоев из встроенной галереи
- Своя картинка из галереи / Minio
- Анимированные фоны (Lottie)
- Размытие / приглушение фона

### Виджеты (Android / iOS)

- Виджет «Последние чаты» (размер 4×2): список N последних чатов с аватарами и превью
- Виджет «Быстрый ответ» (4×1): tap → сразу открыть конкретный чат
- Виджет «Статус онлайн» контакта
- Обновление через WorkManager (Android) / WidgetKit (iOS)

### Windows виджет (WPF / Windows 11)

- Tile-уведомление на рабочем столе
- Системный трей с быстрым меню чатов

## Архитектура

### Хранение тем

- Тема = JSON-схема с цветовыми переменными
- Публичные темы хранятся в новой таблице `themes` в [[../Backend/Users]] сервисе
- Пользовательская тема — в настройках профиля (JSONB поле)
- Фоны чатов → Minio ([[../Backend/Files]])

### gRPC методы (Users)

```protobuf
rpc SaveTheme(SaveThemeRequest) returns (ThemeResponse);
rpc GetPublicThemes(GetPublicThemesRequest) returns (ThemesListResponse);
rpc SetChatBackground(SetChatBackgroundRequest) returns (Empty);
```

## Android виджет — техническая реализация

```kotlin
// AppWidgetProvider
class ChatsWidgetProvider : AppWidgetProvider() {
    override fun onUpdate(...) {
        // WorkManager job → gRPC запрос последних чатов → RemoteViews
    }
}
```

- Использует существующий gRPC-стек Android-клиента [[../Клиенты/Android]]
- Хранит кеш данных виджета в SharedPreferences (обновляется каждые 15 мин)
- Поддержка Glance API (Jetpack) для декларативного UI виджета
