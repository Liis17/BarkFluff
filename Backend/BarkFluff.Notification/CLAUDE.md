# Микросервис Notification

## Описание

Микросервис `Notification` отвечает за отправку уведомлений пользователям в системе BarkFluff.

## Механика работы

Сервис потребляет сообщения из RabbitMQ и отправляет уведомления пользователям. В настоящее время поддерживается только отправка уведомлений по электронной почте.

## Возможности

*   Отправка уведомлений по электронной почте.
*   Потребление сообщений из RabbitMQ для отправки уведомлений.

## Технический стек

*   **Фреймворк:** ASP.NET Core
*   **Обмен сообщениями:** RabbitMQ (с использованием MassTransit.RabbitMQ)
*   **Другое:** MediatR

## Зависимости

*   **RabbitMQ:** Используется для получения сообщений от других сервисов, которым необходимо отправить уведомление.
*   **Микросервис Configuration:** Используется для обнаружения других сервисов.
