# Аудит Безопасности: BarkFluff.FastAuth

**Дата аудита:** 4 марта 2026 г.  
**Аудитор:** Security Assessment Team  
**Статус:** 🔴 СЕРВИС НЕ ГОТОВ К ПРОДАКШЕНУ

---

## Резюме

Сервис BarkFluff.FastAuth **не готов к продакшену**. Большинство методов не реализованы, критическая бизнес-логика отсутствует.

---

## Критические проблемы

### 1. Отсутствие реализации бизнес-логики
| Файл | `Features/GenerateConnectDeviceToken/GenerateConnectDeviceTokenCommandHandler.cs` |
|------|-----------------------------------------------------------------------------------|
| **Уровень** | 🔴 Критический |

**Описание:**
```csharp
public Task<GenerateConnectDeviceTokenResponse> Handle(...)
{
    _logger.LogWarning("Попытка вызова неимплементированного метода");
    throw new NotImplementedException();
}
```

**Статус:** Все методы возвращают `NotImplementedException`

---

### 2. Отсутствие политики авторизации FastAuth
| Файл | `Backend/BarkFluff.GrpcServer/XAuth/XAuthExtensions.cs` |
|------|---------------------------------------------------------|
| **Уровень** | 🔴 Критический |
| **CWE** | CWE-284: Improper Access Control |

**Описание:**
- В системе определен `TokenType.FastAuth = 3`
- Отсутствует политика `options.AddPolicy(nameof(TokenType.FastAuth))`
- Невозможно использовать авторизацию для FastAuth токенов

**Исправление:**
```csharp
options.AddPolicy(nameof(TokenType.FastAuth),
    p => p.RequireClaim(IdentityClaims.TokenType, "FastAuth"));
```

---

### 3. SubscribeFastAuthRequests без авторизации
| Файл | `fast_auth_api.proto` |
|------|-----------------------|
| **Уровень** | 🟠 Высокий |
| **CWE** | CWE-200: Information Exposure |

**Описание:**
```protobuf
message SubscribeFastAuthRequestsRequest { }
```
- Любой пользователь может подписаться на все запросы быстрого входа в системе

**Исправление:**
- Добавить `[Authorize(Policy = nameof(TokenType.FastAuth))]`
- Включить `user_id` в запрос

---

### 4. SubscribeFastAuthResult без авторизации
| Файл | `fast_auth_api.proto` |
|------|-----------------------|
| **Уровень** | 🟠 Высокий |

**Описание:**
- Метод не требует авторизации
- Зная `fast_auth_id`, любой может подписаться на результат

**Исправление:**
- Требовать авторизацию для подписки

---

### 5. Отсутствие rate limiting
| Файл | `Host/FastAuthApiService.cs` |
|------|------------------------------|
| **Уровень** | 🟠 Высокий |

**Исправление:**
- Не более 10 токенов в минуту на пользователя

---

### 6. XSS через device_name/os_name
| Файл | `fast_auth_api.proto` |
|------|-----------------------|
| **Уровень** | 🟡 Средний |

**Описание:**
```protobuf
message FastAuthRequest {
  string device_name = 3; // Имя устройства
  string os_name = 4;     // Имя ОС
}
```

**Исправление:**
- Валидация на уровне API
- HTML-экранирование при отображении

---

### 7. Неопределенный срок действия токенов
| Файл | `fast_auth_api.proto` |
|------|-----------------------|
| **Уровень** | 🟠 Высокий |

**Описание:**
- Нет стандарта на срок жизни токена
- В документации упоминается "2 минуты", но это не enforced

**Исправление:**
- Установить фиксированный срок (2-5 минут)

---

### 8. Сервис не имеет базы данных
| Файл | `Program.cs` |
|------|-------------|
| **Уровень** | 🔴 Критический |

**Описание:**
```csharp
// Нет DbContext – миграции не нужны
```

**Исправление:**
- Добавить PostgreSQL или Redis для хранения сессий

## Рекомендации

**НЕ РАЗВЕРТЫВАТЬ В ПРОДАКШЕН!**

1. Реализовать всю бизнес-логику
2. Добавить политику авторизации FastAuth
3. Реализовать хранение сессий (PostgreSQL/Redis)
4. Добавить авторизацию на все streaming методы
5. Внедрить rate limiting
6. Добавить валидацию и sanitization входных данных
