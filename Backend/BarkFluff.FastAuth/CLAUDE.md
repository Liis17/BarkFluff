# Микросервис FastAuth

## Описание

Микросервис `FastAuth` предоставляет быстрый и легковесный способ аутентификации устройств в системе BarkFluff.

## Механика работы

Сервис предоставляет gRPC API для выполнения следующих операций:

*   **Генерация токена подключения устройства:** Генерирует токен, который может быть использован для аутентификации устройства.

## Возможности

*   Быстрая и легковесная аутентификация устройств.

## Технический стек

*   **Фреймворк:** ASP.NET Core
*   **API:** gRPC
*   **Другое:** MediatR, QRCoder

## Зависимости

*   **Микросервис Configuration:** Используется для обнаружения других сервисов.
