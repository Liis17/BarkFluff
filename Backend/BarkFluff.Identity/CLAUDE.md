# Микросервис Identity

## Описание

Микросервис `Identity` отвечает за аутентификацию, авторизацию и управление сессиями пользователей в системе BarkFluff.

## Механика работы

Сервис предоставляет gRPC API для выполнения следующих операций:

*   **Регистрация:** Новые пользователи могут создать учетную запись, предоставив необходимую информацию.
*   **Аутентификация:** Пользователи могут войти в систему, используя свои учетные данные (логин и пароль). В случае успеха сервис генерирует JWT-токен и токен обновления.
*   **Управление токенами:** Сервис позволяет обновлять JWT-токены с помощью токенов обновления.
*   **Управление паролями:** Пользователи могут устанавливать, сбрасывать и подтверждать сброс своих паролей.
*   **Двухфакторная аутентификация:** Пользователи могут включать, отключать и подтверждать двухфакторную аутентификацию.
*   **Управление сессиями:** Пользователи могут просматривать и завершать свои активные сессии.
*   **Подтверждение учетной записи:** Новые учетные записи должны быть подтверждены с помощью кода, отправленного на электронную почту или телефон.

## Возможности

*   Регистрация и аутентификация пользователей.
*   Генерация и обновление JWT-токенов.
*   Безопасное хранение паролей.
*   Сброс и восстановление паролей.
*   Поддержка двухфакторной аутентификации.
*   Управление активными сессиями.
*   Подтверждение учетной записи.

## Технический стек

*   **Фреймворк:** ASP.NET Core
*   **API:** gRPC
*   **База данных:** PostgreSQL (с использованием Npgsql.EntityFrameworkCore.PostgreSQL)
*   **Обмен сообщениями:** RabbitMQ (с использованием MassTransit.RabbitMQ)
*   **Аутентификация:** JWT (с использованием System.IdentityModel.Tokens.Jwt)
*   **Двухфакторная аутентификация:** Otp.NET, QRCoder
*   **Другое:** MediatR

## Зависимости

*   **PostgreSQL:** Используется для хранения информации о пользователях, токенах обновления и других данных, связанных с аутентификацией.
*   **RabbitMQ:** Используется для отправки уведомлений (например, кодов подтверждения) в микросервис `Notification`.
*   **Микросервис Users:** Взаимодействует с микросервисом `Users` для получения информации о пользователях.
*   **Микросервис Configuration:** Используется для обнаружения других сервисов.
