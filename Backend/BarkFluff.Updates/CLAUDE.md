# Микросервис Updates

## Описание

Микросервис `Updates` отвечает за предоставление обновлений в реальном времени клиентам с использованием потоковой передачи gRPC в системе BarkFluff.

## Механика работы

Сервис предоставляет gRPC API для выполнения следующих операций:

*   **Подписка на новые сообщения:** Клиенты могут подписаться на поток событий о новых сообщениях.

## Возможности

*   Предоставление обновлений в реальном времени с использованием потоковой передачи gRPC.
*   Подписка на события о новых сообщениях.

## Технический стек

*   **Фреймворк:** ASP.NET Core
*   **API:** gRPC (с потоковой передачей)
*   **Обмен сообщениями:** RabbitMQ (с использованием MassTransit.RabbitMQ)
*   **Другое:** MediatR

## Зависимости

*   **RabbitMQ:** Используется для получения событий о новых сообщениях от микросервиса `Messages`.
*   **Микросервис Configuration:** Используется для обнаружения других сервисов.
