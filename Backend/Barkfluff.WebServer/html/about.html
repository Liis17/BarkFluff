О проекте BarkFluffAbout BarkFluff

BarkFluff — некоммерческий проект распределённого мессенджера с открытым исходным кодом. Мы создаём приложения для общения и возможность развернуть собственный сервер.BarkFluff is a noncommercial, open-source distributed messenger project. We build apps for communication and make it possible to run your own server.

Что мы разрабатываемWhat we are building

BarkFluff объединяет серверную платформу обмена сообщениями, нативные приложения и веб-клиент. Администраторы могут разворачивать свои ноды — серверы BarkFluff — и управлять их инфраструктурой.BarkFluff brings together a messaging server platform, native apps and a web client. Administrators can deploy their own nodes — BarkFluff servers — and manage their infrastructure.

Проект активно развивается. На главной доступны сборки для Windows, macOS и Android, а также ссылка на веб-клиент. Клиенты для iOS и Linux находятся в разработке. Актуальные версии публикуются на главной, изменения — в GitHub.The project is in active development. The home page offers Windows, macOS and Android builds, plus a link to the web client. The iOS and Linux clients are in development. Current versions are listed on the home page, and changes are tracked on GitHub.

О прежнем использовании barkfluff.comAbout the previous use of barkfluff.com

В 2022 году этот домен использовал другой магазин товаров для животных. Нынешний проект BarkFluff и его команда не связаны с тем магазином, его владельцами, заказами или платежами.In 2022, this domain was used by an unrelated pet-products store. The current BarkFluff project and its team are not affiliated with that store, its owners, orders or payments.

Совпадение доменного имени не означает преемственности. Сегодня barkfluff.com — сайт некоммерческого проекта мессенджера с открытым исходным кодом. Старые публикации о магазине относятся к прежнему использованию домена.Sharing the domain name does not imply continuity. Today, barkfluff.com is the website of a noncommercial, open-source messenger project. Old publications about the store concern the domain's previous use.
