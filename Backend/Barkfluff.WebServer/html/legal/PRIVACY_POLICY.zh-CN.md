# BarkFluff 隐私政策

**生效日期：** 2026 年 1 月 24 日  
**最后更新：** 2026 年 11 月 19 日（第 2 版）

> 本译文仅供参考。如有歧义，以俄文版本为准。

## 1. 谁对您的数据负责

BarkFluff 是由相互独立的服务器（“节点”）组成的联邦网络。每个节点由其管理员部署和运维；节点之间相互通信，以连接不同节点的用户。

对于 barkfluff.com 公共节点，个人数据控制者是以个人身份运营的 BarkFluff 首席开发者，位于亚美尼亚。该节点的主服务器位于德国。BarkFluff 是开源项目，并未注册为法人实体。运营者的联系邮箱列于本文末尾。

BarkFluff 的开发者为由其他管理员独立运营的节点发布软件和协议规范。作为软件作者，他们不运营这些节点、无法访问其数据、密钥、流量或备份，也不处理有关这些数据的请求。首席开发者另以个人身份运营 barkfluff.com 公共节点，详见上文。

本文件描述软件在默认配置下的行为，适用于 **barkfluff.com** 节点。任何其他节点的管理员都会发布自己的版本，并有权修改配置或源代码——届时以其条款为准。如果您的账户不是在 barkfluff.com 上创建的，请联系您所在节点的管理员。

## 2. 节点管理员在技术上能看到什么

- 普通的单聊和群聊消息以明文形式存储在节点上。节点管理员对数据库、文件存储和日志拥有技术访问权限，**可以读取其内容**。
- 私密聊天在服务器上只保存密文；密钥在您的设备上由 passphrase 派生，不会传给节点。
- 秘密聊天仅由节点在设备之间转发，不作为历史记录保存。
- 如果您不愿意信任某个节点的管理员，请使用私密聊天或秘密聊天，或者自行部署节点。

## 3. 处理哪些数据

### 3.1 账户与个人资料

| 数据 | 用途 | 存储位置 |
| --- | --- | --- |
| 电子邮件 | 注册、登录、确认、找回访问权限及通知，包括账户封禁与删除通知 | Users / Identity；限制原因与日期会与账户一并保存 |
| 用户名 | 登录、搜索、公开个人资料页面、在聊天中显示 | Users |
| 密码哈希 | 密码校验；不存储明文密码 | Identity |
| 名字、姓氏、简介 | 用户资料与公开资料数据 | Users |
| 头像与资料封面 | 个人资料及公开页面的展示 | Files / Minio + Users 元数据 |
| 隐私与个性化设置 | 资料数据的展示、客户端外观、是否允许联邦聊天 | Users |

### 3.2 设备与会话

| 数据 | 用途 | 存储位置 |
| --- | --- | --- |
| Device ID | 绑定刷新令牌、活动会话列表、撤销会话 | Identity.RefreshTokens、Users.UserDevices |
| 设备名称 | 显示与重命名设备 | Users.UserDevices |
| 操作系统、应用名称 | 客户端兼容性与设备列表 | Users.UserDevices |
| Location | 在会话列表中显示设备 | Users.UserDevices |
| Firebase 令牌 | 通过 Firebase Cloud Messaging 推送通知 | Users.UserDevices |
| 刷新令牌 | 续期会话与从设备退出登录 | Identity.RefreshTokens |

部分客户端会在 gRPC 元数据头 x-ip-address 中发送 IP 值。节点会在请求上下文中使用这个由客户端提供的值；它不是可信的 IP 来源，也不属于节点间请求使用的 XFed 标头。这并不表示外部服务看不到网络 IP：远端服务端点可看到其连接的源 IP；详见第 7 节。

### 3.3 消息、聊天与文件

| 数据 | 用途 | 存储位置 |
| --- | --- | --- |
| 普通消息 | 单聊与群聊、同步、已读回执、编辑与删除 | Messages / PostgreSQL |
| 私密加密聊天 | 采用客户端加密的一对一聊天，仅限同一节点内 | Messages 保存密文与聊天元数据 |
| 秘密聊天 | 特定设备之间的一对一聊天，仅限同一节点内 | 节点转发 envelope 并临时缓冲 |
| 附件与预览 | 传输文件、图片、视频、文档、音频与头像 | Files / Minio + PostgreSQL 元数据 |
| 已读状态 | 显示已读消息 | Messages |

### 3.4 在线状态与更新

Onliner 保存并提供在线状态和最后活动时间。Updates 通过 gRPC streaming 向客户端推送实时事件。

### 3.5 网站与支持

WebServer 提供公共网站、个人资料页面、法律文件和公开资料 REST API。在 barkfluff.com，网站支持消息保存在 WebServer 进程内的本地历史记录中，并转发至 Telegram 支持聊天。进程重启时，本地历史记录会丢失。运营者表示，Telegram 支持聊天会每周自动清理一次；这是对聊天的定期清理，不是每条消息各自的保存期限。目前尚未确认本地历史记录的清理计划。

发送到运营者服务邮箱的请求可能在没有既定最长期限的情况下保存。运营者表示，服务发送的验证码不会保存在运营者自己的邮箱中；这不代表 Identity 的处理情况，也不代表收件人邮箱中的保存情况。

在公开个人资料页面点击“在浏览器中发消息”时，WebServer 会创建短时 cookie `bf_open_chat`，以便 Web 客户端打开与所选用户的聊天。

### 3.6 通话、机器人和推送通知

Calls 会在节点数据库中保存通话会话的技术信息，包括参与者、通话类型、状态以及开始、接听和结束时间。通话媒体通过 LiveKit 转发。公共节点运营者表示，服务器不会录制通话媒体。此说明不涵盖通话元数据、参与者设备上的数据或其他节点；LiveKit 的托管方式和数据保存期限尚未确认。

如果您向机器人发送消息或文件，这些内容会通过 API 交付给该机器人。机器人运营者可按其自身规则处理或保存收到的内容。设备推送令牌存储在 Users 中；启用相关功能时，后端代码通过 Firebase Cloud Messaging 发送通知。普通移动 FCM data payload 可能包含 chat_id、sender_id、sender_name、avatar_url、chat_title、chat_avatar_url、is_group_chat、content_type、image_url、message_id、message_text（最多 100 个字符的预览）和 attachment_count。私密消息 payload 包含 private_chat_id、event_id 和 sender_user_id；秘密消息 payload 包含 event_id、sender_user_id 和 sender_device_id。这两种 payload 均不包含消息文本。是否使用 APNs 或其他平台推送服务尚未确认。

## 4. 联邦数据交换

联邦默认关闭（`Federation:Enabled = false`），由节点管理员开启。开启后，当您与其他节点的用户通信时，部分数据会越过您所在节点的边界。

| 发往其他节点的内容 | 时机 | 方式 |
| --- | --- | --- |
| 标识符、用户名、姓名与资料头像 | 当其他节点的用户找到您或打开您的资料卡时 | 节点间的资料查询，遵循您的隐私设置 |
| 消息正文、编辑、删除、已读回执 | 与其他节点用户的一对一会话 | 签名事件；队列会重试投递 |
| 文件与附件 | 当对方打开文件时 | 应对方节点请求以流式提供；不会预先创建副本 |
| 在线状态与最后活动时间 | 联邦聊天处于活动状态期间 | 节点间的实时流；适用您的隐私设置 |
| “正在输入…” | 您输入消息时 | 一次性通知，不予保存 |

需要明确的要点：

- 联邦聊天仅限一对一单聊。不支持跨节点的群聊。
- **联邦消息没有端到端加密。** 其内容对您所在的节点和对方所在的节点均可见。私密聊天与秘密聊天仅在同一节点内可用。
- 接收数据的节点会成为其副本的**独立控制者**。您的节点和开发者都无法控制该节点保存这些数据的时长与方式。其模型与电子邮件相同。
- 联邦消息删除会作为事件发送给参与节点，并在收到和验证后应用；投递和应用并非同步完成。这不会删除已下载的文件或屏幕截图。barkfluff.com 的账户删除不会传播到其他节点，也不会清除已交付的数据。
- 您可以在隐私设置中拒绝接收联邦单聊——此后从其他节点发起的建聊请求将被拒绝。
- 您所在节点的管理员可以整体封禁某个节点，与其的数据交换即告终止。

**技术保证及其边界。** 节点间事件使用 Ed25519 签名，连接使用 TLS 并校验服务器密钥指纹，请求在有限时间窗口内签名。这能证明数据**来自哪个节点**且在传输中未被篡改，但对该节点管理员如何处置所收到的副本不提供任何保证。

## 5. 数据的用途

- 注册、登录、两步验证、找回密码与会话管理；
- 个人资料、用户搜索、公开页面与隐私设置；
- 投递消息、文件、已读回执、实时更新与推送通知；
- 在联邦开启时与其他节点的用户交换消息；
- 通过 `Users.ExportData` 导出用户数据；
- 通过节点管理员配置的渠道提供用户支持；处理账户限制与删除请求，向账户电子邮件地址发送相关通知，并将限制原因与日期和账户一并保存。账户最终删除时会删除限制原因；
- 记录错误、指标与安全事件。

## 6. 数据保护

### 6.1 数据传输

- 客户端与微服务在外部边界使用 gRPC/HTTP/2 与 HTTPS/TLS。
- gRPC 请求的鉴权使用 XAuth 元数据：`x-auth-token`、`x-device-id`、`x-device-name`、`x-ip-address`、`x-os`、`x-app-name`、`x-app-version`。
- 内部异步事件通过 RabbitMQ / MassTransit 传递。
- 节点之间的流量走单独的安全通道，详见《加密》。

### 6.2 密码、令牌与两步验证

- 密码以哈希形式存储。
- Access token 是位于 `x-auth-token` 头中的 JWT；有效期由您所在节点的 Identity 配置决定。
- 刷新令牌绑定到 Device ID，保存在 Identity 中。
- 两步验证支持 TOTP 验证器与邮件验证码。

### 6.3 加密聊天

- **私密聊天：** 节点保存 `EncryptedMessage` 密文、nonce 与 AAD；密钥在客户端由 passphrase 和聊天盐值派生。
- **秘密聊天：** 节点处理与设备绑定的不透明 envelope，将其转发给接收方并以 24 小时 TTL 缓冲。
- **普通聊天：** 消息保存在您所在节点的 Messages 服务中，服务端逻辑与节点管理员均可访问。

## 7. 向第三方提供数据

个人数据不会被出售。根据公共节点的功能和配置，数据可能会发送给：

- 联邦网络中的其他节点，参见第 4 节；每个接收节点自行负责其副本；
- 用于账户邮件的已配置 SMTP 服务；具体邮件服务商尚未确认；
- 启用时用于推送通知的 Firebase Cloud Messaging；
- 用于转发网站支持消息的 Telegram Bot API；
- 用于通话的已配置 LiveKit 服务器；其托管方式、运营者和元数据处理情况尚未确认；
- 已检查的首页和隐私政策页面响应包含 server: cloudflare 和 Network Error Logging (NEL) 标头；浏览器从 fonts.googleapis.com 和 fonts.gstatic.com 加载 Google Fonts。

外部服务可看到其网络连接的源 IP：浏览器直接发起请求时是浏览器的 IP，服务器发起请求时是节点服务器的出口 IP。这并不表示服务商会保存该地址；其处理方式和保存期限尚未确认。请勿根据节点自身的存储实践推断服务商的做法。


## 8. 用户权利

有关您数据的请求请发给您所在节点的管理员——只有他能够执行。

- **访问与导出：** 导出会返回 JSON 文件 `profile.json`、`messages.json` 与 `files.json`。
- **更正：** 资料、简介、头像、封面、隐私、设备与密码可通过客户端中可用的功能修改。
- **删除：** 请求处理后，账户进入为期 7 天的待删除状态；此后由后台任务执行清理，若发生错误需要重试，完成时间可能延后。详情请参阅[《账户删除政策》](/legal/account-deletion)。
- **撤销会话：** 可通过设备管理功能结束活动会话。
- **限制联邦：** 可在隐私设置中拒绝接收联邦单聊。

## 9. 删除消息与数据

- 普通消息支持通过 Messages API 删除。
- 私密加密消息在删除时被标记为已删除，密文被清除。
- 秘密消息在确认送达或 TTL 到期后从临时缓冲中删除。
- 联邦消息删除会发送至参与节点，并在收到和验证后应用；投递和应用并非同步完成。这不会删除对方已下载的文件或屏幕截图。barkfluff.com 的账户删除不会传播到其他节点，也不会清除已交付的数据。
- 若需删除账户以及客户端功能未覆盖的数据，请联系节点运营者。请求处理后，账户将处于“待删除”状态 7 天；此后由后台任务执行清理，若发生错误需要重试，完成时间可能延后。详情请参阅[《账户删除政策》](/legal/account-deletion)。

### 公共节点上的保存期限

据运营者称，公共节点的日志和备份没有设定最长期限。此前可能进入其中的数据在账户删除后仍可能保留。这并不表示备份一定包含任何特定数据，也不表示备份始终存在或一直保存；本说明不涉及第三方服务商的保存期限。其他类别数据的实际保存期限尚未确认。

## 10. Cookie 与本地存储

- 网站使用 barkfluff_chat_id（支持聊天标识符，最长 1 年）、bf_open_chat（从公开资料页跳转到 Web 客户端，最长 5 分钟）和 bf_cookie_notice（提示确认记录，最长 1 年）。
- 网站使用 localStorage 中的 bf_lang 保存语言，并使用 bf_domain_notice_v1 记住用户关闭了域名历史提示；未设置单独过期时间。
- Web 客户端使用 bf_theme（主题）、bf_lang（语言）和 bf_legal_accepted（已接受的条款与政策版本）Cookie，最长 1 年。访问令牌保存在 localStorage 或 sessionStorage。
- 原生客户端在本地存储令牌、设置和缓存；Windows 可用 PIN 保护 GlobalParam.json，macOS 使用 Keychain。
- 公共网站从 fonts.googleapis.com 和 fonts.gstatic.com 加载字体。首页和隐私政策页面已确认包含 Cloudflare 标头和 Network Error Logging (NEL)；浏览器可能会向已配置端点发送网络错误报告。
- BarkFluff 不会有意设置分析或广告 Cookie。外部请求可能向服务商发送技术数据；参见第 7 节。


## 11. 儿童

barkfluff.com 公共节点仅面向年满 16 周岁的用户。其他节点自行设定年龄规则。如果您认为未满 16 周岁的用户在 barkfluff.com 注册，请联系 privacy@barkfluff.com。

## 12. 政策变更

本政策变更时会更新“最后更新”日期。重大变更可能通过应用或电子邮件告知。节点管理员自行发布其版本的变更。
