Политика удаления аккаунта

Действует с: 24 января 2026 г. Обновлено: 17 июня 2026 г.

1. Введение

Эта страница описывает, как запросить удаление аккаунта Barkfluff и какие категории данных обрабатываются при таком запросе.

2. Как запросить удаление аккаунта

Отправьте запрос на privacy@barkfluff.com с адреса, связанного с аккаунтом, или укажите данные, которые помогут подтвердить владение аккаунтом.

  • username;
  • email, использованный при регистрации;
  • краткое описание запроса;
  • дополнительные сведения для подтверждения владения аккаунтом, если доступа к email нет.

Ответ по запросам удаления: до 7 рабочих дней.

3. Какие данные относятся к аккаунту

4. Что происходит с сообщениями

  • Обычные сообщения поддерживают удаление через Messages API.
  • Приватные encrypted-сообщения при удалении помечаются как удаленные, а шифротекст очищается.
  • Секретные сообщения не сохраняются как обычная история на сервере: сервер ретранслирует envelope и временно буферизует его до доставки или истечения TTL.
  • Если сообщение уже доставлено другому пользователю или включено в историю чата, обработка запроса учитывает целостность истории для других участников и применимые юридические обязанности.

5. Экспорт данных перед удалением

В Barkfluff есть gRPC-метод Users.ExportData. Он формирует JSON-данные:

  • profile.json — профиль пользователя;
  • messages.json — сообщения и чаты, где пользователь является участником;
  • files.json — метаданные файлов, связанных с профилем и сообщениями.

Если вам нужен экспорт перед удалением, укажите это в обращении на privacy@barkfluff.com.

6. Частичное удаление и отзыв доступа

  • Сообщения можно удалять через функции клиента, использующие Messages API.
  • Активные сессии можно завершать через управление устройствами.
  • Firebase token хранится на устройстве в Users.UserDevices и используется для push-уведомлений.
  • Аватар и постер профиля меняются или очищаются через функции профиля и персонализации.

7. Контакты

  • Удаление и приватность: privacy@barkfluff.com
  • Поддержка: support@barkfluff.com

Account Deletion Policy

Effective from: January 24, 2026. Updated: June 17, 2026.

1. Introduction

This page describes how to request deletion of a Barkfluff account and which categories of data are processed for such a request.

2. How to request account deletion

Send a request to privacy@barkfluff.com from the address associated with the account, or provide details that help confirm ownership of the account.

  • username;
  • the email used at registration;
  • a brief description of the request;
  • additional details to confirm account ownership if you no longer have access to the email.

Response time for deletion requests: up to 7 business days.

4. What happens to messages

  • Regular messages support deletion via the Messages API.
  • Private encrypted messages are marked as deleted on deletion, and the ciphertext is cleared.
  • Secret messages are not stored as regular history on the server: the server relays the envelope and buffers it temporarily until delivery or TTL expiry.
  • If a message has already been delivered to another user or included in chat history, processing the request takes into account history integrity for other participants and applicable legal obligations.

5. Data export before deletion

Barkfluff provides the gRPC method Users.ExportData. It produces JSON data:

  • profile.json — the user profile;
  • messages.json — messages and chats where the user is a participant;
  • files.json — metadata of files associated with the profile and messages.

If you need an export before deletion, mention it in your request to privacy@barkfluff.com.

6. Partial deletion and access revocation

  • Messages can be deleted through client features that use the Messages API.
  • Active sessions can be terminated via device management.
  • The Firebase token is stored on the device in Users.UserDevices and used for push notifications.
  • The profile avatar and poster are changed or cleared through profile and personalization features.
