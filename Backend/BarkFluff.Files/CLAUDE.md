# Микросервис Files

## Описание

Микросервис `Files` отвечает за управление хранением и извлечением файлов в системе BarkFluff.

## Механика работы

Сервис предоставляет gRPC API для выполнения следующих операций:

*   **Загрузка файлов:** Позволяет загружать файлы в систему. Сервис генерирует URL-адрес для загрузки, который клиент может использовать для загрузки файла напрямую в Minio.
*   **Скачивание файлов:** Позволяет скачивать файлы из системы. Сервис генерирует временный URL-адрес для скачивания, который клиент может использовать для скачивания файла напрямую из Minio.
*   **Получение метаданных:** Позволяет получать метаданные о файлах, такие как имя, размер и тип.

## Возможности

*   Загрузка и скачивание файлов.
*   Получение метаданных о файлах.
*   Взаимодействие с S3-совместимым хранилищем (Minio).

## Технический стек

*   **Фреймворк:** ASP.NET Core
*   **API:** gRPC, REST
*   **База данных:** PostgreSQL (с использованием Npgsql.EntityFrameworkCore.PostgreSQL)
*   **Объектное хранилище:** Minio (с использованием AWSSDK.S3)
*   **Обработка изображений:** SixLabors.ImageSharp
*   **Другое:** MediatR

## Зависимости

*   **PostgreSQL:** Используется для хранения метаданных о файлах.
*   **Minio:** Используется для хранения фактического содержимого файлов.
*   **Микросервис Configuration:** Используется для обнаружения других сервисов.
