# Микросервис Configuration

## Описание

Микросервис `Configuration` обеспечивает централизованное управление конфигурацией для всех микросервисов в системе BarkFluff.

## Механика работы

Сервис предоставляет gRPC API для выполнения следующих операций:

*   **Получение конфигурации:** Другие микросервисы при запуске могут запрашивать свою конфигурацию у этого сервиса.

## Возможности

*   Централизованное хранение и предоставление конфигурации для всех микросервисов.

## Технический стек

*   **Фреймворк:** ASP.NET Core
*   **API:** gRPC
*   **База данных:** PostgreSQL (с использованием Npgsql.EntityFrameworkCore.PostgreSQL)
*   **Другое:** MediatR

## Зависимости

*   **PostgreSQL:** Используется для хранения данных конфигурации для всех сервисов.
