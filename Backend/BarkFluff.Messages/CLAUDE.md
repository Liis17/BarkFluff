# Микросервис Messages

## Описание

Микросервис `Messages` отвечает за управление обменом сообщениями в реальном времени между пользователями и группами в системе BarkFluff.

## Механика работы

Сервис предоставляет gRPC API для выполнения следующих операций:

*   **Управление чатами:** Позволяет создавать групповые чаты и получать список чатов пользователя.
*   **Обработка сообщений:** Позволяет отправлять, получать и помечать сообщения как прочитанные.
*   **Управление пользователями в чатах:** Позволяет исключать пользователей из чатов и получать список участников чата.

## Возможности

*   Создание и управление групповыми чатами.
*   Отправка и получение текстовых сообщений и вложений.
*   Отслеживание статуса прочтения сообщений.
*   Управление участниками чата.

## Технический стек

*   **Фреймворк:** ASP.NET Core
*   **API:** gRPC
*   **База данных:** PostgreSQL (с использованием Npgsql.EntityFrameworkCore.PostgreSQL)
*   **Кеширование:** Redis (с использованием Microsoft.Extensions.Caching.StackExchangeRedis)
*   **Обмен сообщениями:** RabbitMQ (с использованием MassTransit.RabbitMQ)
*   **Другое:** MediatR

## Зависимости

*   **PostgreSQL:** Используется для хранения информации о чатах и сообщениях.
*   **Redis:** Используется для кеширования информации о чатах.
*   **RabbitMQ:**
    *   Публикует события при отправке новых сообщений, которые потребляются микросервисом `Updates`.
    *   Потребляет события от микросервиса `Users` для обновления информации о пользователях в чатах (например, при изменении имени или аватара).
*   **Микросервис Users:** Взаимодействует с микросервисом `Users` для получения информации о пользователях.
*   **Микросервис Files:** Взаимодействует с микросервисом `Files` для обработки вложений в сообщениях.
*   **Микросервис Configuration:** Используется для обнаружения других сервисов.
